# 快速打印 & 文档扫描 UI 增强设计

**Goal:** 优化快速打印和文档扫描页面的用户体验：打印机能力感知、文件预览、操作反馈、导航保护。

**Architecture:** 在现有 PySide6 GUI 基础上增量修改，复用 `win32print.DeviceCapabilities` 实现打印机能力检测，封装 `PrintDialog` 共享打印逻辑。

**Tech Stack:** PySide6, pywin32 (win32print), PIL (thumbnails)

---

## 1. 打印机能力感知

### 1.1 默认打印机自动填充

- 页面加载时，调用 `win32print.GetDefaultPrinter()` 获取系统默认打印机名
- 在 `_refresh_printers()` 填充打印机列表后自动选中
- 如果 Config `default_printer` 有值，则优先使用配置值（和默认不冲突时可覆盖）

### 1.2 能力检测

新增 `_on_printer_changed(printer_name)` 方法，通过 `DeviceCapabilities` 获取：

| 能力 | API 常量 | 返回值 | UI 影响 |
|---|---|---|---|
| 最大份数 | `DC_COPIES` (17) | int | 动态设置 SpinBox 上限，无值兜底 99 |
| 彩色支持 | `DC_COLORDEVICE` (23) | 1=彩色, 0=黑白 | 黑白色 → 下拉只显示"黑白" |
| 双面支持 | `DC_DUPLEX` (29) | 1=支持, 0=不支持 | 不支持 → 隐藏双面开关，内部标记 duplex=False |
| 支持纸张 | `DC_PAPERNAMES` (16) | 字符串列表 | 动态填充纸张下拉框 |

### 1.3 UI 控件变更

- **颜色**：LabeledToggle 改为 QComboBox，选项 `["彩色", "黑白"]`
- **纸张**：QComboBox 从固定 `["A4", "Letter", "A3"]` 改为动态填充
- **双面**：LabeledToggle 保留，打印机不支持时 `setVisible(False)`

### 1.4 全局默认值

Config 中的默认值不受打印机能力影响。打印页面在显示时根据打印机能力调整 UI，隐藏的选项自动设回默认值避免提交无效参数。

### 1.5 B&W 处理

不做图像预转换。Windows 打印机驱动自动处理彩色→黑白转换。

## 2. 文档扫描打印弹窗 (PrintDialog)

将当前内联打印面板改为独立的模态对话框 `PrintDialog(QDialog)`：

### 2.1 布局

```
┌──────────────────────────────────┐
│  打印设置                         │
├──────────────────────────────────┤
│  打印机:  [xxxxxxxxx    ▼]       │
│  份数:    [3  ▲▼]                │
│  颜色:    [彩色/黑白    ▼]        │
│  双面:    [■ 双面]               │
│  纸张:    [A4          ▼]        │
│                                  │
│        [取消]  [确认打印]         │
└──────────────────────────────────┘
```

### 2.2 复用

- 打印机能力检测逻辑封装为 `_update_printer_capabilities(printer_name)`，快速打印的内联面板和扫描的弹窗共享
- 弹窗初始化时读取当前页面已选打印机作为默认值

## 3. 未保存离开确认

### 3.1 检测

两个页面增加 `_has_unsaved_content() -> bool` 方法，返回是否有已上传文件尚未提交。

### 3.2 拦截

在 `MainWindow._on_nav_changed(index)` 中：
- 切换到新页面之前检查当前页面是否有未保存内容
- 有则弹出 `QMessageBox.question()` 确认框：
  - 标题："未保存更改"
  - 文本："当前页面有未提交的文件，离开后数据将清空，是否离开？"
  - 按钮：`离开` / `取消`
- 点击"离开" → 调用当前页面的 `_clear_all()` 清空数据 → 切换页面
- 点击"取消" → 不切换

---

## 4. 清除按钮

两个页面标题行右侧添加"清除"按钮：

- **图标/文字**：`✕ 清除`
- **Tooltip**：`"清除所有已选文件和结果，重新开始"`
- **点击行为**：
  - 弹出 `QMessageBox.question()`："确定要清除所有已选文件吗？此操作不可撤销。"
  - 确认 → 调用 `_clear_all()` 清空
  - 取消 → 不做操作
- **`_clear_all()` 方法**：清空文件列表、隐藏结果/进度/actions、重置内部状态

## 5. 文件预览与信息增强

### 5.1 缩略图

- 图片文件（jpg, png, bmp, gif, webp, tiff, heic）在文件列表左侧显示 48x48 缩略图
- 非图片文件（pdf, docx, xlsx）显示对应文件类型图标（用图标文本代替：📎 PDF, 📊 Excel, 📝 Word）

### 5.2 路径显示

文件列表项格式：
```
文件名.ext  (父文件夹\文件名.ext)
```
路径部分中间截断，Tooltip 显示完整路径。

### 5.3 打开文件

点击文件列表的文本区域调用 `subprocess.Popen(["explorer", file_path])` 打开文件。

## 6. 操作反馈

### 6.1 打印过程反馈

- 提交打印 → 按钮显示加载状态 + 进度条
- 打印完成 → 按钮变成功状态 + 标签显示"任务 #X 已完成"
- 打印失败 → 按钮变错误状态 + 标签显示错误信息

### 6.2 文档扫描导出反馈（另存为）

- 点击"导出" → 弹出 `QFileDialog.getSaveFileName()`（类似 Word 另存为）
- 根据输出格式设置默认扩展名：PDF → `.pdf`，图片 → `.jpg`
- 导出完成后：
  - 状态标签显示：`"已导出: C:\Users\...\scan_result.pdf"`
  - 显示两个按钮：`打开文件` 和 `打开所在文件夹`
  - "打开文件" → 用默认程序打开
  - "打开所在文件夹" → `explorer /select,文件路径` 打开并高亮文件
